# Security Policy

## Supported Versions

PassGen adheres to an offline-first, client-side cryptographic security model.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

Security and privacy are foundational pillars of PassGen. If you discover a security vulnerability or cryptographic flaw:

1. **Do NOT report security vulnerabilities through public GitHub issues or discussions.**
2. Please use **GitHub Private Vulnerability Reporting** via the [Security tab](https://github.com/cyberlog69/pass-gen/security/advisories/new) of this repository.
3. Include detailed reproduction steps, threat model context, and potential impact.

We strive to acknowledge receipt within 48 hours and work with you to patch any confirmed vulnerabilities before public disclosure.
